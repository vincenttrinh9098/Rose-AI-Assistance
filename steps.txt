### /Core
* Create core/audio_io.py:
    Allows user to record their audio, output in a file and main.py handles the functionality of repeating back the message

* core/dispatcher.py: 
    Handles the functionality part of the core, the command is parse through, dispatcher decides what functions need to be called

### /Commands
* commands/browser.py:
    Handles queries that have to do with browsers (open, search on google....)

* commands/applications.py:
    Handles all commands that have type [URL,native_apps] ( spotify, google, notes, discord,etc...)
    



### /Ai 
* /ai/llm.py
    Handles parsed text from dispatch.py -> claude restructures into json format after understanding user intent
